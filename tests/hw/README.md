# Hardware Tests
This folder contains the project files for the hardware tests. The tests are designed to verify the functionality of the ILA on the actual silicon.

## Test 00: Basic test with AXI4SPktGen IP
AXI4SPktGen is a simple AXI4-Stream packet generator IP that can be used to generate packets for testing purposes. The test will configure the AXI4SPktGen IP to generate a specific pattern of packets.
