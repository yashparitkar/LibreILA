# Drivers for LibreILA
This directory contains the drivers for the LibreILA. There are two types of drivers:
1. Baremetal drivers for use with cores on fpga
2. Python driver for interfacing with the UART version

## Directory structure
```text
drivers/
├── baremetal/ : C drivers to use with LibreILA cores on FPGA
├── python/    : Python driver to interface with the UART version of LibreILA
└── README.md  : This file
```
