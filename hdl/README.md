# LibreILA HDL files
This directory contains the HDL files for the LibreILA

## Directory structure
```text
hdl/
├── fifo.vhdl           : A generic fall through fifo buffer
├── libre_ila_uart.vhdl : UART wrapper for the LibreILA
├── libre_ila.vhdl      : LibreILA core
├── README.md           : This file
└── uart.vhdl           : UART driver
```
